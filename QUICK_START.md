# CFB-Jay: Quick Start & Navigation

## 🚀 Getting Started

Welcome to the **CFB-Jay College Football Max Dominance Vault** - a comprehensive database of elite college football performances spanning 1970-2026 across all D1 conferences.

### Quick Navigation

1. **View index.html** - Opens master vault index in your browser
2. **Browse CSV data** - Raw performance statistics in `/data/` directory
3. **Read documentation** - Full guides in `/docs/` directory
4. **Run Python script** - Generate HTML profiles: `python scripts/generate_profiles.py`

## 💻 How to Use

### Casual Browsing
1. Open `index.html` in your browser
2. Browse players by era
3. Click player name to view full profile
4. Each profile has YouTube links and complete stats

### Data Analysis
1. Download CSV files from `/data/`
2. Open in Excel, Google Sheets, or Python
3. Analyze trends across eras/conferences
4. Compare offensive/defensive systems

### Generate HTML Profiles
1. Run: `python scripts/generate_profiles.py`
2. Generates individual profiles for all 51+ players
3. Creates master index with era-based navigation
4. Outputs organized by era in `/profiles/`
