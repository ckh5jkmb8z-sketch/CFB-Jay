# CFB-Jay: College Football Max Dominance Vault

## Overview
Comprehensive database of documented standout performances across all D1 conferences (1970-2026), featuring:
- Heisman winners and record-holders
- Elite performers (Trent Richardson, Dri Archer, Billy "White Shoes" Johnson, Jeff Demps, Josh Cribbs, Charles Tillman, and 200+)
- Game-by-game slash lines (passing, rushing, receiving, defensive stats)
- Season and career statistics
- Theoretical maximum performances
- Advanced analytics (EPA, success rates, efficiency metrics)
- **Embedded YouTube videos (full game + highlights)**
- Organized by era, conference, offensive/defensive system, and milestone type

## Data Schema

Each CSV includes:
- **Player Name & Position**
- **Conference & School**
- **Year/Era**
- **Game/Season/Career Slash Lines** (stats by category)
- **Theoretical Maximum Performance**
- **Advanced Analytics** (EPA, success rate, efficiency %)
- **Offensive/Defensive System**
- **YouTube Full Game Link** (Column A - Direct broadcast)
- **YouTube Highlights Link** (Column B - Partial/curated)
- **Milestone Classification** (Heisman, All-American, record-holder, era-defining)
- **Spoiler-Free Description** (game context, performance highlights, no results spoiled)
