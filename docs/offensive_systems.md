# Offensive Systems Reference

## System Classifications by Era

### 1970s-1980s: Classic Era Systems
- **Wishbone** - Triple-option, fullback dive dive/pitch
- **Veer** - Veer option, dive read option
- **Power Option** - Defensive end read, pull guard lead
- **Straight Option** - QB keep/pitch decision
- **I-Form** - Two RBs, power running
- **Split-Back Veer** - Two RBs in offset looks

### 1980s-1990s: Hybrid Transition
- **Run & Shoot** - Empty backfield, 4-5 WR sets
- **Air Raid** - Spread principles, shotgun pass-first
- **Spread** - Wide receiver splits, spacing emphasis
- **Go-Go** - Uptempo, four-wide receiver sets
- **Pro-Style** - NFL-style formations, multiple TE packages

### 1990s-2000s: Modern Systems
- **Slow Mesh** - Deliberate read option with TE motion
- **Spread Option** - Spread formation + veer reads
- **Shotgun Spread** - Spread from shotgun snap
- **525 (Spread package)** - 5 WRs, 2 RBs, 5 OL
- **335 (Spread package)** - 3 WRs, 3 RBs, 5 OL
- **326 (Spread package)** - 3 WRs, 2 RBs, 1 TE, 5 OL

### 2000s-2010s: Modern Spread Era
- **44 (4 WR, 4 RB)** - Full four-wide receiver sets
- **52 (5 WR, 2 RB)** - Five receiver emphasis
- **46 (4 WR, 6 OL)** - Extra lineman for power
- **Nickel (5 WR, 1 RB)** - Receiver-dominant packages
- **Dime (5+ WR)** - Pure passing sets
- **Read Option** - QB read on defensive end
- **Pistol Formation** - QB offset from center

### 2010s-2020s: Modern Hybrid
- **Tempo Spread** - Uptempo run-pass option (RPO)
- **Zone Read** - Zone blocking with QB read
- **Triple Option** - Modern option principles
- **Air Raid Modern** - High volume passing, TE usage
- **Spread-to-Win** - Defensive gap responsibility reads
- **Run & Shoot Modern** - Hybrid run-pass blend
- **Shotgun Stretch** - Spread formation with outside zone runs

## Statistical Tracking by System

For each system:
- **Success Rate %** - Plays gaining positive EPA
- **Average Yards/Play** - Total yards / total plays
- **TD Efficiency** - Touchdowns per scoring opportunity
- **Standard Deviation** - Consistency of performance
- **EPA/Play** - Expected Points Added per play
- **Conference Dominance** - Win % when system used
