# Player Performance Categories

## Classification System

### Tier 1: Historic Dominance
- **Heisman Trophy Winners** - National award recipients
- **National Record-Holders** - All-time statistical leaders
- **All-American Selections** - Multi-year elite selections
- **Era-Defining Performances** - Changed how position/game played

### Tier 2: Conference Elite
- **Conference MVP/Award Winners**
- **All-Conference Selections** - Multi-year
- **Conference Record-Holders**
- **Milestone Achievers** - 1000+ yard rushers, 3000+ yard passers, etc.

### Tier 3: Notable Specialists
- **Position-Specific Dominators** - Exceptional in narrow role
- **Special Teams Mastery** - Return specialists, kick specialists
- **Defensive Standouts** - Unit leaders, turnover generators
- **Situational Performers** - Dominant in specific game types

## Performance Metrics

### Offensive Metrics
- **Volume Stats** - Yards, attempts, receptions
- **Efficiency Metrics** - Yards/attempt, TD:INT ratio
- **Advanced Stats** - EPA/play, success rate %, explosive play frequency
- **Consistency** - Standard deviation, reliability
- **Peak Performance** - Best single game stats

### Defensive Metrics
- **Volume** - Tackles, sacks, interceptions, TFLs
- **Efficiency** - Tackles for loss/game, sack rate
- **Advanced** - QB pressure %, EPA allowed, win rate when playing
- **Coverage Prowess** - Interceptions, pass deflections, allowable yards
- **Discipline** - Penalties per game, gap control

### Special Teams Metrics
- **Return Yards** - Kick return, punt return averages
- **Touchdown Returns** - Scores from special teams
- **Coverage Efficiency** - Opponent return yard limiting
- **Placement** - Field goal/extra point accuracy
- **Consistency** - Game-to-game performance
